Ideal curve

Default: a generic coaching shape, with a quick catch, one smooth peak about 40% of the way through the drive, no dips, and a smooth finish. Coaches differ on the exact shape, so set it to yours.

Backup

Sessions live in this browser's storage on this phone. Export a backup now and then (to Google Drive, iCloud, email…). Clearing browser data deletes them.

Units

The PM5 reports force in pounds; ErgCurve converts to newtons (× 4.448). Raw values are kept in the saved data, so nothing is lost if the scale ever needs correcting.

Recording

Off (default): you tap Start recording after your warm-up, so warm-up and drills never touch your averages.

About

Needs a PM5 with the green Concept2 logo on recent firmware. Only one app can be connected to the PM5 at a time, so close ErgData first. Android: use Chrome. iPhone: use the Bluefy browser (Safari and Chrome on iOS have no Web Bluetooth).
